# CareFlow Hospital Demo

A self-contained browser demo for hospital intake, casualty triage, ward transfers, clinical notes, prescriptions, observations, and simulated notifications.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Important

This is a front-end simulation. Authentication, notifications, and records are stored locally in the browser and are not production security or clinical systems. Do not enter real personal or medical information.
